# UI prototype (superseded)

The mobile-first Vite prototype that explored the site's look before the real
website existed. It lived in `web/` until the production site was built there.

**The live site is [`web/`](../../../web/)** — Next.js, documented in
[web/README.md](../../../web/README.md). Anything here is history, not a
dependency: nothing builds it and nothing imports from it.

Kept because a prototype records intent that finished code does not. If you
want to run it:

```bash
cd docs/reference/ui-prototype
npm install
npm run dev
```
